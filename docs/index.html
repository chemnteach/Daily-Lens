Supreme Court Blocks GOP-Favored Missouri Congressional Map
The Supreme Court has blocked Missouri's use of a Republican-drawn congressional map that would have created a 7-1 GOP advantage in the state's delegation. The decision overturned a federal judge's order that had directed the state to implement the new boundaries for the November election, leaving an alternative state court map in place instead. Left-leaning outlets emphasize the Court's rejection of Republican gerrymandering efforts, while right-leaning sources note this marks the second time the Court has blocked the map and reference an ongoing contempt hearing. The ruling creates clarity around which district boundaries will govern the upcoming midterm elections in Missouri.
