Trump Administration Challenges 400 Washington State Ballots
The Trump administration's Justice Department has requested that Washington state set aside approximately 400 ballots from voters it alleges are registered without U.S. citizenship. The move represents the administration's latest effort to challenge voting eligibility in competitive states ahead of midterm elections that could influence congressional control. Left-leaning outlets frame this as part of a broader pattern of ballot challenges in contested races, while mainstream sources present it primarily as a factual account of the Justice Department's request. Election officials in Washington state are processing the request as the matter unfolds.
